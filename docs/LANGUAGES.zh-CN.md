# 双语材料的写作与维护约定

[English](LANGUAGES.md) | [简体中文](LANGUAGES.zh-CN.md)

中文和英文都是本项目直接撰写的正式材料。两份从同一组研究事实和表达目标出发，各自按照自然的行文方式组织，不经过互译流水线，也不要求逐句套同一种结构。前提、公式、数字、失败结果和当前状态必须一致。

研究档案保留原有中文阶段记录，并补充面向英文读者独立组织的版本。公开文字采用我作为项目发起者的视角，去除助手会话的叙述痕迹。DeepSeek、WorkBuddy 的提案保留来源，不能把提案中的判断直接变成已验证成果。历史停止点仍明确保留其时间背景。

每份说明性文档都有另一种语言的对应入口。代码、模式、标识、哈希、测量值和引用元数据共用规范资产，并通过完整的中英文资料清单解释，避免产生行为或数字不同的副本。Apache 官方许可证不改写成另一份法律文件，中文项目说明另行解释我的许可选择。

一个结论发生变化时，我会同时更新两个语言版本及其依据。覆盖检查负责文档配对与导航，关键事实另做定点核对；文件数量齐全不等于每句话已经完成等价性证明，更不代表新增实验成立。
