# 发布范围与持续维护约定

[English](PUBLICATION.md) | [简体中文](PUBLICATION.zh-CN.md)

我把 SERA 作为持续演进的公开研究档案维护，公开内容包括架构选择、冻结协议、原型代码、汇总结果、修正记录，以及保留来源归属的外部研究提案。这个仓库不镜像我的整个私有工作区。

凭据、知识库正文、私人问题、向量、数据库、逐请求记录、训练产物及本地环境不上传。对于无法公开输入的实验，私有实验记录仍是运行事实的依据；没有纳入 Git 不代表可以换个渠道传播。

中文和英文依据同一份事实与表达目标分别直接撰写，各自遵循自然的行文结构，不以其中一种语言为底稿互译。两份材料必须守住相同的实验条件、公式、状态和结论边界。外部方案保留其来源，不能改写成我已经独立验证的成果。

代码、标识、数值和哈希维持单一规范版本，配套提供中英文阅读说明，避免制造行为不同的可执行副本。Apache-2.0 官方许可证保持原文；中文许可说明解释我的选择，不替代正式条款。

每完成并审查一个研究部分，我将对应协议、代码、结果和限制一起提交。失败记录保留，被替代的判断注明版本；重要里程碑可再制作标签、Release 和 DOI 归档。目前没有配置自动研究或自动发布任务。

项目原创代码与文档采用 Apache-2.0；第三方依赖及另行标识的材料沿用各自许可。研究进展、工程可用、新颖性和代际提升仍分别判断。
