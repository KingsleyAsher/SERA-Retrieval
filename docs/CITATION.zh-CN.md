# 如何引用本项目与实验结果

[English](CITATION.md) | [简体中文](CITATION.zh-CN.md)

机器可读引用信息保存在 `CITATION.cff`。项目全名为 SERA：Stateful Execution for Retrieval Architectures，维护账号为 KingsleyAsher，仓库地址为 https://github.com/KingsleyAsher/SERA-Retrieval。首次公开档案日期是 2026-10-29，这个日期不代表同行评审发表或正式发布的实验研究。

引用某个数字时，请同时注明具体提交和对应阶段报告，并说明快照、代码哈希、工作负载及质量指标。输入私有的结果需要明确标识。尤其不要把相对 JSON 的布局改进写成超过 ANN，也不要把向量前十重合写成语义准确率。

外部提案或论文应另行引用实际来源。集成决定、模型辅助提案、可执行简查和实测结果属于不同证据。后续重要里程碑可以申请 DOI，目前尚未分配。
