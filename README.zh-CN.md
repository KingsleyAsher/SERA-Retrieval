# SERA：面向稀疏激活与状态复用的检索架构研究

[English](README.md) | [简体中文](README.zh-CN.md)

**面向新型检索架构的前沿研究，探索稀疏激活、状态复用与预测预取。**

SERA（Stateful Execution for Retrieval Architectures）从个人知识库出发，研究将检索、候选复用、资料变化修复和预测性工作纳入共享版本状态与资源账本，能否减少重复工作，同时改善检索质量、响应速度、资源效率、更新新鲜度和稳定性。逐步探索向大规模知识库扩展的能力。

## 当前状态 · 2026-10-29

阶段二工程骨架、阶段三第一部分候选复用和第二部分紧凑缓存／可控 IVF 已完成。第三部分只有协议，尚未实施。专家模型训练暂停；预测预取、严格认证与大规模验证仍属待推进研究。

当前实验包含 1,213 片段、114 来源，使用 BGE-M3 dense1024。阶段三只使用 16 个开发查询族、48 个不同文本（含 32 个改写）；多轮回放不等于新增独立样本。语义标签尚未核实。

| 已观察结果 | 必须同时说明的限制 |
|---|---|
| 紧凑布局 C50 合并耗时由 JSON 的 7.517 ms 降至 4.006 ms，约降低 46.7% | 是布局工程收益，不能表述为相对成熟 ANN 的架构加速 |
| 16 分区、总评分预算 256 时，种子引导使平均向量前十重合由 84.375% 提至 97.8125% | 最差仍为 80%，耗时增加；重合率不是语义准确率 |
| 实现可控前沿、种子评分和有预算的接续 | 仍有待验证的部分分区覆盖约束；不构成严格认证 |

尚未证实相对强基线的稳定综合优势、正式语义质量提升、超大库效果或代际提升。
