# SERA：面向稀疏激活与状态复用的检索架构研究

[English](README.md) | [简体中文](README.zh-CN.md)

**面向新型检索架构的前沿研究，探索稀疏激活、状态复用与预测预取。**

我发起 SERA，希望研究一种能够协调检索、候选复用、更新修复与预测性工作的新架构。核心假设是，共享版本状态、依赖关系和资源账本可以减少重复工作，改善语义质量、响应速度、资源效率、更新新鲜度和稳定性。我从个人知识库起步，只有在证据支持时才向更大规模推进结论。

## 当前进展：2026-10-29

共享执行骨架、阶段三第一与第二部分已经完成。第三部分已形成协议，尚未实施。专家训练继续暂停；预测预取、学习式停止和严格认证仍属于研究方向，不能当作已经交付的能力。

私有冻结快照包含 114 个来源、1,213 个片段，采用 BGE-M3 dense1024。阶段三诊断使用 16 个开发问题族、48 个不同文本，其中 32 个为改写；语义标签尚未核实。

| 阶段观察 | 结论边界 |
|---|---|
| 紧凑 C50 合并由 JSON 的 7.517 ms 降至 4.006 ms | 布局工程收益可重复，不能写成已超过成熟 ANN |
| IVF16、预算 256，C200 种子使平均向量前十重合由 84.375% 提至 97.8125% | 总评分次数相同，最差仍为 80%，耗时增加 |
| 与强基线比较 | 相对成熟 ANN 或最佳冷 IVF 点的稳定净优势仍未证实 |

本项目目前不据此宣称正式语义质量提升、超大库效果、已确认新颖性或代际进步。
