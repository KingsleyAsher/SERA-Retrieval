# Stage-2 interfaces and replay boundaries

[English](接口与复现说明.en.md) | [简体中文](接口与复现说明.md)

I expose backend differences through a common execution contract rather than rebuilding the experiment for each route. `Request` binds vector/text, backend, K, snapshot, `Scope`, scoring contract, quality target, limits, deadline and cache policy. A compatible request must preserve its identity when resuming.

`Scope` carries source prefix and update cutoff. `Store` publishes versioned SQLite histories and produces a snapshot whose identity binds its namespace, revision and digest. `Engine` validates that the snapshot belongs to the store and matches model/dimension. The repaired schema stores content hashes; unsupported historical schemas are rejected rather than migrated implicitly.

`Execution` retains signature, snapshot, phase, prepare substep, candidate positions, scores, selection, source actions, cursor and consumed resources. `Ledger` admits known counter costs atomically. The supplied save ledger may not erase historical consumption. Counts are cumulative across continuation; timing describes the present call only. Extra checkpoints have their own cost.

The full path uses canonical float64 inner product and stable ID ties. ANN generates candidates with USearch, then reranks canonically. Hybrid retrieval uses the actual configured dense/lexical pool size in its score-contract label. `ResultCache` serves exact compatible requests, but cache hits still pay source checks and commit. Approximate, probability, certificate, Pending and rejection categories are explicit; unavailable guarantee categories are not fabricated.

I use `check_framework.py` for fictitious mechanics, `review_fix_probes.py` for before/after repair predicates and `check_review_boundaries.py` for the four direct boundaries. These do not need private source text. Real replay scripts require excluded frozen corpus/query/vector assets and the original layout; they are archival protocols rather than public downloadable benchmarks.

Original run-002 timing belongs to its preserved code hash. To inspect old storage behavior, use the matching saved code or explicitly import a fresh isolated store. Never open old performance stores with the new `Store` expecting automatic compatibility. Current source flags mean snapshot-content verification, not original-file verification. Native ANN internal counts are observable but not arbitrarily interruptible hard budgets. Fault injection and concurrent-update validation remain later work.
