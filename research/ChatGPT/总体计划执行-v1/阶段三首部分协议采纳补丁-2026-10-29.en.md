# Candidate-reuse admission protocol

[English](阶段三首部分协议采纳补丁-2026-10-29.en.md) | [简体中文](阶段三首部分协议采纳补丁-2026-10-29.md)

I use this 2026-10-29 addendum to make DeepSeek's fourth protocol executable without changing the six-stage program. The minimum comparison includes ordinary ANN, rescored cached seeds, current ANN candidates merged with seeds, a resource-enhanced fresh ANN and full canonical scoring. Exact old top-C filling is a separate diagnostic. Common exact-request LRU, snapshot/scope/source handling and layout improvements are shared with the baselines.

This first part excludes neighbor graphs, learned risk, sparse blocks, prefetch, strict certificates and true backend warm starts. Each logical query has one parent ledger. Reuse, native search, fallback, source reads, checkpoints and final commit draw from its remaining allowance. Explicitly added allowance preserves prior consumption; insufficient resources yield Pending. A fallback is not a new free request.

The repaired stage-2 state machine is authoritative. Persist entry selection, matching outcome, seed-validation cursor, deduplicated positions, native candidates, scored items and consumed counters. Cache hits still follow common source and commit actions. Unsupported native internal hard caps are rejected. A fully exhausted legal range with N<K can return N; an incomplete cache with enough eligible corpus requires funded new search or an explicit incomplete state, not endless nonprogressing Pending.

Entry selection is stable top-1 current-query inner product over compatible old query vectors, excluding self. Empty post-exclusion buckets fall back. Compatibility does not imply similarity or coverage. Charge matching vectors, metadata and actual seed payload according to actual reads. ANN k=C filling pays search, canonical reranking and storage, and source/commit when it uses the existing full request wrapper. Success items expose ID/version/score, not cleaned internal positions. Record actual C when the legal range is smaller.

Exact old top-C does not upper-bound coverage for a different query: an approximate old set can accidentally retain an item preferred by the new query. Only an explicitly labeled current-query oracle provides that particular upper diagnostic, and cannot be online-free. The 16 paid anchors precede rewrites, never use future queries, and separately warm ordinary k=10 results and k=C candidates. This setup cannot establish natural hits or predictability.

C=10/50/200 and ANN50/ef128 are fixed. Additional ANN count/ef points must be bounded and frozen before final replay. Equal external canonical-score ceilings are only one fairness dimension; native float32 distances, logical reads, setup/fill/maintenance and source/commit remain distinct. Prepare time contains native subtime and must not be counted twice. Do not weaken a 100%-overlap baseline merely to create a comparison, interpolate nonexistent deployable quality points or tune sealed families.

Quality floors and cost goals are independent. Compare attainable quality/cost frontiers and per-query tails. A stronger fresh ANN matching a reuse arm establishes no incremental benefit there, not a universal causal claim. The 16 authored families and their variants support paired development diagnostics, not an automatic iid probability guarantee or formal semantic noninferiority. This document originally stopped at protocol preparation; later execution is recorded separately.
