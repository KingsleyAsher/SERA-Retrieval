# 阶段三第三部分协议：前沿接续、种子计费与界紧度诊断

## 1. 本部分要回答的问题和停止点

核心假设：在合法旧支持项、完整覆盖依赖和可接续执行状态下，块界可能帮助判断哪些区域仍需激活；其规划、缓存和维护成本可能抵消少评分收益。当前均待验证。

本部分分两道门，顺序固定：

1. **先完成实现准入检查**：部分分区中断不得丢尾部，种子评分不得漏计或重复计费。
2. **再做离线界紧度与成本诊断**：量化已有分区上的球界、统计界、组合界及旧界迁移是否留下值得进一步实现的空间。

本部分不直接部署界式停止，不发概率或严格证书，不训练停止模型，不扩大语料或参数网格。完成两道门或触发调整条件后写报告并停止；在线界式停止属于后续需我的确认的部分。

## 3. 采纳与边界

采纳 WorkBuddy 的一般中心距离、正交子空间统计界、max 组合、两界互不支配、在线支持阈值与离线 oracle 分离；采纳 DeepSeek 的种子初始化、排序与上界分工、带 β 的旧查询界迁移。数学前提与浮点实现证明分开。

评分契约固定为日常 `normalized_ip_f64_v1`，K=10、同分 ID 升序，保留当前 BGE-M3 f64 向量坐标，不重新舍入到 FP32。不能通过 `2(1-s)` 把它改称存储 FP32 实数平方 L2 证书。独立 FP32 认证分支、混合排名证书和 OPQ 均不在本部分。

第一轮限同快照、同模型／预处理、同评分、同过滤兼容桶；不启用跨更新或范围扩大复用。需要同时绑定“支持项合法性”和“块界成员覆盖性”，只复核支持项不够。

## 4. 第一优先：部分分区接续

### 4.1 最小状态及含义

| 状态 | 必须表达的事实 |
|---|---|
| `completed_partitions` | 该分区所有合法成员均已评分，或由仍有效的既有分数覆盖；仅排除过的分区另记，不混入此集合 |
| `active_partition` | 当前正在处理但尚未完成的分区；无活动分区时为空 |
| `enumeration_cursor` | 当前分区下一个待读取的成员位置 |
| `pending_positions + score_cursor` | 已枚举但尚未完成评分的项，及已完成前缀；不能因枚举游标前移而删除 |
| `scored` | 当前查询／版本／评分契约下的唯一已计分集合及分数 |
| `order_frontier` | 下一步访问顺序，仅为调度，不提供排除保证 |
| `coverage_frontier` | 全部未完成区域：未开始分区、活动分区剩余成员和未评分 pending 项；未来若使用界堆，三者均须覆盖 |
| `limits + consumed` | 同一请求累计额度和消耗；恢复、种子失败、冷查补齐共用父账 |

实现可以复用现有字段、缓存一个保守整块界或改用可验证等价表示，不要求一定使用两个物理堆；这些事实不能省略。

### 4.2 状态转换不变量

1. 领取分区时记录 active，不能立即标 completed。
2. 读取 posting 后先进入 pending；规范评分真正完成并保存分数后，才进入 scored。分区成员枚举完但 pending 未处理时仍未完成。
3. 如果采用“先取出上界堆项”的写法，取出的活动分区必须同时进入持久活动状态，不能从全局未完成覆盖中消失。
4. 只有该分区合法成员全部由 scored 覆盖、且没有未处理 pending，才可标 completed 并移除其界。分区中的已计分种子可去重，不再取向量或重算。
5. 预算在任何一步耗尽时，保留活动分区、两个游标、pending、分数和消耗；正常 checkpoint／恢复不重复已完成动作。
6. 未来的最大上界检查必须覆盖全部未完成区域。即使排序队列为空，活动分区尾部和 pending 仍可能含最优项，不能据此停止。

这里保证的是有记录的预算中断与正常恢复。进程在计算和持久化之间崩溃的物理“恰好一次”语义不在当前能力范围，不能凭状态字段声称已解决。

### 4.3 首要反例

保留交接反例：已有种子得分 0.5，分区内依次为 0.6、0.95，评分首项后预算耗尽。恢复必须仍能处理 0.95；不能因先写 visited/completed 或弹出整个界而丢掉它。

同时覆盖“posting 已枚举但一个分数都未算”“最后一个 posting 已枚举但最后一次评分未完成”“表内全是已评分种子”三种边界。

## 5. 第二优先：种子与全部动作计费

对每次实际规范评分，发起前原子检查并扣除该动作涉及的硬资源；完成后同时推进分数和游标。计数维度可以分类，但不能把分类当额外评分再加一次。

- 一个新种子的元数据 ID／版本读取、版本与过滤校验、库向量读取、规范评分分别记录。当前 1024 维 f64 向量载荷为 8192 B／项；16 B ID／版本不是向量载荷。
- `canonical_scores = seed_scores + new_scan_scores + other_new_scores`；字节按实际布局记。以上等式仅统计真实新评分，缓存中依赖完全一致的有效旧分数允许复用，但读取／验证成本仍记。
- 已有当前查询分数的种子与后续扫描碰到的同 ID／版本去重；“只读了 ID 以便跳过”记 posting／元数据，不再记向量读取和评分。
- 旧查询匹配、Δ、范数、界读取／生成、堆操作、来源、提交、初始化、填充和失效维护分别记账。未实现的硬计数限制须拒绝；观测值不能伪装成硬上限。
- 单请求回退继承父账与剩余额度；不自动新建一份额度。不同消融臂各有独立请求账，采用相同规则，不能把前臂消耗带给后一臂。
- 验证任何一个硬资源不够时，整个动作不发起，其他维度也不先扣；正常接续后，评分次数和向量字节与一次不中断执行相同，额外 checkpoint 成本单独增加。

## 6. 第一门通过条件：限定正确性检查

实现时保留原例，新增下列固定检查；不重复整套旧基准：

1. 0.5／0.6／0.95 部分分区反例及新 Engine 恢复。
2. posting 枚举中断与评分中断分别保存，pending 不丢失。
3. 最后一个成员枚举后评分未完成，不可提前 completed。
4. 种子评分预算为 0／只够 1 项时，次数与字节原子扣费；追加额度接续后不漏计。
5. 种子与分区成员重复，只评分一次；字段分类相加等于总数。
6. 排序堆或界堆取出项后中断，未完成区域仍可恢复。
7. 合法范围 N<K 且已穷尽，完整返回 N 项；空范围完成空集。
8. 显式固定预算近似结束和硬预算中断 Pending 区分；缺少可继续动作不得无限 Pending。
9. 范围扩大／新快照时旧覆盖依赖拒绝；同快照同过滤恢复允许。
10. 全范围执行与完整规范评分结果一致；来源和提交路径保留。

前六项任一失败，不进入界诊断的在线执行器集成；先记录失败与修复，不切换指标。若旧实现本已满足某项，用新检查证明保持即可，不为形式重写。

## 8. 界与阈值：明确数学前提与数值状态

块元数据包括成员覆盖指纹、中心 c、半径 ρ、每子空间偏移范数范围 lo/hi、最大成员范数 β、最大成员范数平方 νmax。支持项另存 ID／版本、查询与评分依赖，不能只存 T0 标量。

一般实数几何下：

- `LB_sphere = max(‖q-c‖-ρ,0)²`；`LB_stat = Σ gap(‖(q-c)_m‖,[lo_m,hi_m])²`；`LB_combined=max(...)`。
- 直接内积上界 `U_ball=q·c+‖q‖ρ`，不要求中心单位化。
- 为把 WorkBuddy 的 L2 下界用于**同一坐标下的内积诊断**，可用一般恒等式导出 `U_from_L2=(‖q‖²+νmax-LB)/2`。νmax 覆盖块内所有成员，不能直接写成 1。与直接内积球界取 min 仍为实数上界；分别统计各成分贡献。
- 旧块上界可迁移为 `U0+βΔ`。旧 K 个合法支持项若各至少 T0，支持项范数上界为 βsupport，则新第 K 分数至少 `T0-βsupportΔ`。新支持重评分已获得当前阈值时，用当前阈值，不强行再用旧半径阈值。
- 不声称迁移界必然比任意现算界松；若要比较，记录中心、半径、范数和旧界来源，限定命题前提。
- 排除只考虑严格分离；相等或区间重叠不按 ID 猜测顺序，真实相等后才按 ID。

这些是数学角色定义。普通 f64 得到的诊断数记作 `U_observed/T_observed`，不自动充当保守机器证书；真正的 `U_upper/T_lower` 需要另有数值误差证明。本轮离线比较各界与枚举值，记录原始违反次数和数值间隔，不能用任意 epsilon 隐藏违反，也不因有限样本零违反宣称通用保证。

出现任何界覆盖违反时保存私有最小样例，标记相应数值路径不具备在线保证资格；可以继续报告其他界的离线诊断，但不偷偷换公式或扩大安全带来挽救结果。严格 FP32 实数平方 L2 路径不与此处混用。

## 9. 指标、强基线与可归因范围

逐查询、逐块记录：块大小与剩余成员数，各下界／上界与合法阈值的间隔，sphere_only／stat_only／both／neither（分母为全部合法块），可能排除的唯一向量数、尚需评分数、界规划时间、逻辑读取、统计载荷、支持和匹配成本。

“整块可排除成员数”和“还可避免评分的唯一项数”分开：已付费评分的种子／既有 scored 即使落入可排除块，也不能再记成省掉的工作。筛选门槛只数尚未评分的合法项，分母保留整个合法范围；种子成本始终在总账中。

分别列有支持的在线可构造阈值与离线真 top-K 阈值；后者只作上限诊断，真实穷举验证成本在“评估账”中保留，不冒充检索路径免费 oracle。元数据构建、存储、更新依赖／失效规则和未测维护成本显式列出。

保持 K=10／top10 主指标。未核实语义标签不能用于正式质量提升或非劣结论；不以 top20、块命中率或少枚举 posting 替换原目标。

本部分仅做离线潜力判断，不作查询加速主张。未来若实施在线停止，最小对照将是：

| 臂 | 初始种子 | 顺序 | 停止 |
|---|---|---|---|
| A | 无 | 冷 | 固定总向量预算 |
| B | 无 | 冷 | 同一界规则 |
| C | 同一已付种子 | 冷 | 同一界规则 |
| D | 同 C | 种子引导 | 同一界规则 |
| E | 同 C | 种子引导 | 固定总向量预算（含种子） |

C 对 B 是种子整体增量；D 对 C 才能隔离顺序；D 对 E 是界停止增量。不能把 D 对 B 称为纯排序收益。相同 nprobe 不代表相同总预算；本协议不设置 nprobe=32 等跨块数非法格。成熟 ANN、同布局冷 IVF、完整评分继续作为强对照，支配过的冷点不用于宣称新收益。

此表是后续实验的约束，不授权本部分直接运行五臂在线停止矩阵。
