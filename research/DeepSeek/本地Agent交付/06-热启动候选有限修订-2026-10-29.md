## 2. 接口与状态

**最小接口**（IVF 参考后端尚不存在；这是需求，不是现状）：

```
nlist, dim, centroids C[nlist]（可非单位）, radius ρ[j]=max‖x−c_j‖
members(j), list_of(id), norm_bound β = max‖x‖（单位归一化时 β=1）
bound(q) -> U[nlist]                    # 逐分区有效上界
search(q, frontier, stop_pred, limits)  # 前沿与停止由调用者给定
```

**上界式（本轮修正）**。单位 q、成员范数 ≤ β、质心任意：

```
x = c_j + e, ‖e‖ ≤ ρ_j
⟨q,x⟩ = ⟨q,c_j⟩ + ⟨q,e⟩ ≤ ⟨q,c_j⟩ + ‖q‖·ρ_j = ⟨q,c_j⟩ + ρ_j
```

`U[j] = ⟨q,c_j⟩ + ρ_j` 对任意质心、任意成员范数成立，无单位假设、无分段。05 的角度式只有在把 c 归一化并**按新中心重算半径**后才等价，否则是另一套半径；两者不可混用。

**状态字段**（`Execution` 需持久化，供 Pending 接续）：

```
reuse = { ekey, entry_id, q0_sha, q0_vector, β,
          support:[(id, version, s_q0)] ,      # ≥K，逐条可核
          T0, frontier:{visited:set, order_heap, ub_heap},
          scored:{pos:score}, cursor, stale, verified }
```

`frontier` 与 `scored` 必须一起存。只存标量阈值、不存支持依赖，等于把可失效的结论写死。

## 3. S1：种子前沿注入（修订）

### 3.1 唯一事实源

停止判定只能有**一个**输入：全体未访问分区的有效上界最大值 `Umax`。队列 `Q`（有种子）与 `rest`（无种子）是**排序**上的区分，不是访问状态上的区分。二者必须并进同一个上界堆。

三种边界情形分开处理，不得合并：

- `Umax < T` 且 `|P| ≥ K` → 可停（界分离）。
- 无任何未访问分区 → 停；若 `|P| < K`，状态是 **short**，不是完成。
- 预算耗尽而仍有未访问 → **Pending**，前沿与已计分集落盘。

`T` 未定义（`|P| < K`）时**不能**用 `max(P)` 顶替第 K 名。

### 3.2 双堆

排序与停止用两个不同的堆，键不同、用途不同，不可互相代替：

| 堆 | 键 | 作用 | 可否进停止 |
|---|---|---|---|
| `order` | `B[j]=max` 种子实得分；无种子用 `U[j]` | 决定下一个访问谁 | 否 |
| `ub` | `U[j]=⟨q,c_j⟩+ρ_j` | 决定能否停止 | 是 |

`[推导]` 按表降序访问**不等于**少访问：固定访问数时排序只改变"看到哪些"，不改变"看到多少"。减少访问只可能来自停止规则。这条区别必须写进报告，否则会把排序收益记成访问收益。

### 3.3 伪代码

```
s1(q, entry, K, limits):
    P = {}; visited = set()
    for x in entry.legal_support:              # C 条，逐条 charge
        charge(seed_verifications=1, candidate_bytes_read=16)
        P[x] = <q,x>
    T = kth_best(P, K)                         # |P|<K 时为 None
    charge(bound_stats=nlist)                  # 上界统计单独计费
    ub = MaxHeap({j: U[j] for j unvisited}); order = MaxHeap(prio)

    while True:
        while ub and ub.top in visited: ub.pop()
        Umax = ub.top_key() if ub else -inf
        if T is not None and Umax < T:  return topK(P,K), 'bound_separated'
        if not ub:                      return (topK(P,K),'exhausted') if T is not None else (P,'short')
        if limits_exhausted():          return PENDING(visited, order, ub, P)
        j = order.pop_unvisited(); visited.add(j)
        for x in members(j):
            if x in P: continue                # 已计分不重复访问
            charge(vector_reads=1, canonical_scores=1)
            P[x] = <q,x>
        T = kth_best(P, K)
```

### 3.4 成功例 `[构造]`

3 个分区，`K=1`。扫描首个分区得 `P={0.90, 0.80}`，`T=0.90`；未访问两分区上界 `U=0.55, 0.60`，均 `< 0.90` → 停。冷启动同预算 `nprobe=3` 需扫 3 个分区。

差别来自停止规则，不来自排序。若把上界换成 `0.95`（界太松），同一例不停，访问数回到 3 —— 这就是收益消失的方式，也是必须实测 `U` 紧度的原因。

### 3.5 失败反例：只查 `Q` 会漏 `rest` `[构造]`

`K=1`，已计分项最优 `0.80`（`T=0.80`）；`Q` 已空，`Q` 内上界 `≤0.70`；`rest` 中一分区上界 `0.99`，其中 `y` 真实得分 `0.95`。

二维实现：`q=(1,0)`，`y=(0.95,0.3122)`；取 `c=y`、`ρ=0.04`，则 `U=⟨q,c⟩+ρ=0.95+0.04=0.99`；已计分项 `x=(0.8,0.6)` 给出 `T=0.80`。

05 伪代码在 `Q` 空后对空集取 `max`（或 guard 成 `-inf`），判 `0.80 > -inf` 成立 → 停 → 返回 `0.80`，漏掉 `0.95`。

**修正手算**：`Umax = max(rest) = 0.99 ≥ 0.80` → 不停；访问该分区；`P` 增入 `0.95`，`T=0.95`；重算 `Umax`（剩余 `≤0.6`）`< 0.95` → 停，返回 `0.95`。

### 3.6 四消融（缺一不可归因）

| 臂 | 顺序 | 停止 | 用途 |
|---|---|---|---|
| A | 冷（质心分） | 固定 `nprobe` | 现役做法参照 |
| B | 冷（质心分） | 同一上界停止 | 隔离**停止规则** |
| C | 种子排序 | 固定访问数＝A | 隔离**排序** |
| D | 种子排序 | 同一上界停止 | 完整机制 |

归因只允许：`D−B` = 种子排序贡献（同停止规则）；`D−C` = 停止规则贡献（同排序）。**`A` 与 `D` 不能直接相减**：两者停止规则不同，差值里混着"保证强度不同"，不能全记给缓存。C/D 扫到含种子分区时必须跳过 `P` 中已计分项，且四臂共用父 Ledger。

## 4. S2：查询增量界预剪枝（修订）

### 4.1 支持项取代"旧全局 top-K"

`T0` 不必是旧查询的全局第 K 名。充要形式是：

> 存在 **K 个互不相同、当前合法**（存在、版本一致、可见、在 scope 内）的项，其旧查询精确分各 `≥ T0`。

则新查询第 K 名 `≥ T0 − βΔ`。证明：每项 `⟨q,x⟩ = ⟨q0,x⟩ + ⟨q−q0,x⟩ ≥ T0 − ‖q−q0‖·‖x‖ ≥ T0 − βΔ`，K 项成立即得。

要点：只要求这 K 项的分数**可核为精确值**，不要求它们是旧查询的前 K 名，也不要求排序。因此 ANN 填充的种子可以直接充当支持项。

### 4.2 依赖与失效

支持依赖 = `(snapshot, scope, K, score_contract, 每条 id+version+score)`。任一不符即失效：

| 变化 | 处理 |
|---|---|
| 版本变更／删除／不可见 | 该支持项作废；不足 K 项 → S2 不可用，退回冷启动 |
| scope 收窄 | 必须重算（支持项可能被滤掉） |
| scope 放宽 | 界仍保守可用，但须重核支持项合法性 |
| 快照前移（含新增） | 支持项须逐条版本核验；本轮不做跨快照复用，不符即失效 |

### 4.3 伪代码

```
s2(q, q0s, K, limits):
    sp = []; for (id,ver,s) in q0s.support:            # 逐条 charge
        charge(seed_verifications=1,candidate_bytes_read=16)
        if legal(id,ver,scope,snapshot): sp.append((id,ver,s))
    if len(sp) < K: return COLD(q)                      # 阈值不可得
    T0 = min(s for _,_,s in sp[:K])                      # 只需下界
    Δ  = ‖q − q0s.q0_vector‖;  β = q0s.β
    T_lb = T0 − β*Δ
    ub = MaxHeap({j: q0s.U0[j] + β*Δ})                   # 零新库向量读取
    P = {}
    while ub:
        θ = kth_best(P,K) if len(P)>=K else T_lb
        if ub.top_key() < θ: break                       # 严格小于才剪
        j = ub.pop()
        for x in members(j):
            if x in P: continue
            charge(vector_reads=1, canonical_scores=1); P[x]=<q,x>
    return topK(P,K), 'empirical_pruned'
```

`T0` 取 K 个支持项分的**最小值**，不是最大值——用最大值会把阈值抬高到不成立。

### 4.4 成功例 `[构造]`

`q0=(1,0)`，`q=(0.88,0.47497)`，`Δ=0.48990`，`β=1`。支持项 `x=(0.5,0.86603)`，`s_q0=0.5`，`K=1` → `T0=0.5`，`T_lb=0.01010`。尾分区 `y=(−1,0)`，`U0=−1` → `U_q ≤ −1+0.48990 = −0.51010 < 0.01010`，剪掉。核验：`⟨q,y⟩=−0.88 < 0.01010`，安全。

**该例 `Δ=0.49 > 0.45` 仍可剪枝**，故"Δ>0.45 即落窗外"不成立：间隔还取决于 `T0`、`U0` 与该分区的几何。

### 4.5 失败反例 `[构造]`

- **支持不足**：`K=10`，合法支持只有 3 项 → `T_lb` 不存在，`ub` 无阈值可比，剪枝为零；必须退回冷启动，不能"用一个标量阈值"硬撑。
- **几何不受控**：同一 `Δ`，若尾分区 `U0` 不低（例如 `U0=0`，`Δ=1.414` 的正交查询），`U_q ≤ 1.414 ≥ T_lb`，一个分区也剪不掉。

### 4.6 与"现算质心"的基线比较（决定 S2 是否值得做）

成熟基线可为当前 q 现算 `U[j]`，成本 `nlist·d`。而迁移界 `U0+βΔ` 恒 `≥ U_q`，即**更松**，能剪的分区只会更少。S2 的净收益只能是：

```
省下的粗算 nlist·d  −  因界变松而多扫的分区数 × 每分区代价
```

`[推导]` `nlist=√N` 时，`nlist·d` 恰等于**一个**分区的扫描代价；此时 S2 要在"多扫一个分区以上"的劣势下取胜，几乎不可能。`nlist` 远大于 `√N`（多而小的分区）时粗算才变贵，S2 才有空间。**所以 S2 的可行域由 `nlist` 决定，不只由 `Δ` 决定**——这是 05 完全没考虑的一层。

## 5. 记账与接续

近似状态不豁免记账，逐项落实：

1. **逐动作预扣**：种子校验按条 `charge`，扫描按分区/批 `charge`，上界统计 `bound_stats=nlist` 单独计；匹配、布局、维护、来源、提交各列。
2. **接续**：Pending 存 `visited`、两个堆、`scored`、`cursor`、支持依赖；恢复不重做已完成动作。【待验证提议】
3. **数值保守性**：`U` 必须**向上**舍入、`T_lb` **向下**舍入，否则剪枝可能剪掉真项。浮点方向未闭合前，一律称**经验剪枝**，不得同时称"数学无损"。
4. **可证性分级**：`bound_separated` 只是"在该界实现下分离"，不是实数精确证书；仍发 `approximate`。

## 6. 撤回的未测结论

- "`.90–.96` 是典型改写区间"：无本项目 `Δ`／`cos` 实测分布。首部分只报了重合率与耗时，未报相似度分布。
- "窗口 `cos ≳ .99`"：由假定的 `M` 太小推得，`M` 未测；§4.4 反例已说明 `Δ` 单独不足判。
- "1,213 片段基本不可能"：该结论依赖 `nprobe=8`。`nprobe` 是自由参数，同一 `C/√N` 要求在大 `nprobe` 下宽松得多（`nprobe=32` 时只需省 6 个分区）。**不得据此排除个人小库。**
- 规模表：`nlist=√N`、等表长、固定 `nprobe` 均为示例配置，不是最优律。

保留的代数式（前提写全）：等表长、`nlist=√N`、同召回下，`访问节省成立 ⟺ nprobe − nprobe' > C/√N`。
