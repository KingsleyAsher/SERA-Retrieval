### 1.5 W6 四项具体修正

1. **余弦**：若 `s_k` 已是余弦相似度，阈值 `τ=2(1−s_k)`；**不得再取 `cos`**。若 `s_k` 是夹角才用 `cos`。
2. **slack 符号统一**：`slack = d* − max(d_c−ρ,0)`（距离单位，非负）。上一稿 D1 写成 `(d_c−ρ)−d*`，符号相反。
3. **C1 换为单位实例**：`B={(1,0),(−1,0)}`，`q=(0,1)`，`c=(0,0)`，`ρ=1` → `LB_sphere=0`、真最小平方距 `2`、阈值 `1`；球界漏剪，`LB_stat=2>1` 可补剪。原 `d_c=2,ρ=1` 的壳层不是单位向量实例，撤下。
4. **D5 分母**：所有比例一律以**全部合法块**为分母；若要条件统计"被剪块内"，须显式写明条件分母，否则 `neither` 恒为 0。

## 2. 修正后的证明链

### 2.1 W1：中心距离（不再假设单位质心）

对任意 `q,c`：

```
‖q−c‖² = ‖q‖² + ‖c‖² − 2⟨q,c⟩
‖q‖=1 时：  = 1 + ‖c‖² − 2⟨q,c⟩
```

反例：`B={(1,0),(−1,0)}`，`c=(0,0)`，`q=(0,1)`。真值 `‖q−c‖²=1`；误用 `2−2⟨q,c⟩` 得 `2`。直接送入下界会**过估** `d_c` 并错剪。

**若改用单位中心方向** `ĉ=c/‖c‖`（`c≠0`）：`‖q−ĉ‖²=2−2⟨q,ĉ⟩`（`q,ĉ` 均单位）。但必须同时重建：

```
ρ̂ = max_x ‖x−ĉ‖
[lô_m, ĥî_m] = 块内 ‖(x−ĉ)_m‖ 的取值范围
```

不得把旧 `ρ`、旧 `[lo,hi]` 直接配新 `ĉ`。`c=0`（如对跖点）时 `ĉ` 无定义，保留算术中心。

> 说明：单位成员的算术平均一般不是单位向量，这是**一般线性代数事实**，不是 BGE-M3 独有性质。BGE-M3 模型卡支持 dense 1024 维；归一化、存储精度、严格比较均由本项目契约规定，不能由模型名推出。

### 2.2 W2：统计界（不等式链，非等式）

设子空间 `V_m`（`m=1..M`）是坐标的互不重叠划分，`⊕V_m=R^D`；`a=q−c`，`b=x−c`；`t_m=‖a_m‖`，`s_m=‖b_m‖`，且 `s_m∈[lo_m,hi_m]`。

```
(1) gap(t_m,[lo,hi]) ≤ |t_m − s_m|                    // 点到区间的距离 ≤ 到区间内任一点
(2) | ‖a_m‖ − ‖b_m‖ | ≤ ‖a_m − b_m‖                   // 反三角不等式
(3) ⇒ gap_m ≤ ‖a_m − b_m‖ = ‖(q−x)_m‖
(4) 平方求和：Σ_m gap_m² ≤ Σ_m ‖(q−x)_m‖² = ‖q−x‖²    // 末等号仅因正交划分
```

**上一稿错误**：把 `Σ_m(t_m−s_m)² = ‖q−x‖²` 当等式。反例：同一二维子空间内 `a=(1,0)`、`b=(0,1)`，`(‖a‖−‖b‖)²=0`，而 `‖a−b‖²=2`。修正后 `LB_stat ≤ ‖q−x‖²` 仍成立，界不必丢弃。

机器实现另需：`lo` 向 RD、`hi` 向 RU、`t_m` 与 `gap_m` 保守、求和保守；本轮不展开。

### 2.3 W3：max 组合——不预设支配

两者各自 ≤ 真距 ⇒ `LB_B=max(·) ≤ 真距`，健全性保留。但**没有**"紧簇远查询统计界更强"的定理；`hi_m` 小不等于其一阶影响可相对球界的 `−ρ` 项忽略。两组相反构造（均为单位向量，取自 `math-checks.json`）：

**构造 A（球界更强）** `B={(±7/25,0,24/25),(0,±7/25,24/25)}`，`q=(2/3,2/3,1/3)`，按三个一维子空间分解：

```
c=(0,0,0.96)，ρ=0.28
LB_sphere ≈ 0.726036
LB_stat   ≈ 0.691733
真最小平方距 ≈ 0.986667
```

**构造 B（统计界更强）** `B={(0,1),(0,−1)}`，`q=(1,0)`：

```
LB_sphere = 0
LB_stat   = 2
真最小平方距 = 2
```

→ 哪项在具体库更强，只能逐块逐查询实测（D5）。上一稿"`LB_stat≈d_c²>(d_c−ρ)²`"至多是附加假设下的启发式，**不能作为比较定理**。

### 2.4 先块界后残差（保留）

顺序不变：块级 `LB_sphere`／`LB_stat`／`max` 先评估；值得继续才考虑逐向量残差。本轮不写 PQ／OPQ。

## 3. 成功例与失败例

| 例 | 构造 | 数值 | 判定 |
|---|---|---|---|
| **S1 球界单独剪** | 构造 A，阈值 `τ=0.70` | `LB_sphere≈0.7260>0.70`；`LB_stat≈0.6917≤0.70`；真最小 `≈0.9867>0.70` | 安全剪；球界可为决定项 |
| **S2 统计界补剪** | 构造 B，阈值 `τ=1` | `LB_sphere=0`；`LB_stat=2>1`；真最小 `2>1` | 球界漏、统计界补、max 安全剪 |
| **F1 两界同漏** | `B={(±1,0),(0,±1)}`，`q=(0.2,0.2)`，`τ=0.5` | `LB_sphere=0`，`LB_stat=0`，真最小 `0.68>0.5` | 本应剪却未剪；power 失败，非不健全 |
| **F2 非保守 ρ 错剪** | 1D：`c=0,q=2`，真 `ρ=1`（点 `x=1`），存 `ρ'=0.9`，`τ=1.1` | 真最小 `1`；`LB'=(2−0.9)²=1.21>1.1` | **不健全**：错排真候选；ρ 必须 RU |
| **F3 单位错配** | `cos=0.5 ⇔ d²=1.0`，阈值误用 `τ=0.5`（余弦单位当 L2） | `1.0>0.5` → 被剪 | 错剪满足 `cos≥0.5` 的候选；阈值须 `2(1−s)` |

### 3.1 区间重叠：不是错误，是"须精化"（W4 撤回原 D6）

`A∈[0,2]`，`B∈[1,3]`；真值可为 `(0.5,1.5)`，也可为 `(1.9,1.1)`。区间相交只说明**区间不足以定序**，不能据此判错。正确纪律：重叠 → 提高比较精度（必要时精确 dyadic）→ 再定序；可统计精化次数与成本，**不得列为正确性错误**。

真正属于错误、必须为零的四类：

```
E1 区间不含真值（LB>真值 或 UB<真值）
E2 基于下界错误排除（被排除项真含 top-k）
E3 最终排序与精确比较不一致
E4 把 |d_A−d_B|≤ε 或 FP64 相等当成精确相等并用 ID 破平
```

> 对各自有效包含真值的闭区间：真实相等 ⇒ 区间必相交（重叠是**必要非充分**）；上一稿"既非必要也非充分"不准确，撤回。

### 3.2 在线阈值 ≠ oracle：不是错误（W5）

设全局第 K 距 `0.2`，当前合法 K 项阈值 `0.8`：

- 块下界 `0.9>0.8` → 按当前阈值可剪，安全；
- 块下界 `0.5`：`0.5>0.2`（oracle 会剪）但 `0.5<0.8`（当前不剪）→ **较弱但安全**，不能判错。

检查项应为：当前阈值是否来自 **K 个不同的合法支持项**、是否与下界**同契约同单位**、阈值方向是否保守。oracle 只作**离线上限诊断**，不假定在线可得。

## 4. 16／64 块最小诊断协议

> 目的：在同一布局、同一停止规则下，观察块粒度（16 vs 64）如何改变组合界的紧度与归因。只做诊断，不引入新架构，不估收益。

**P0 固定条件**：同一向量集、同一分配规则、同一缓存布局、同一 `K`、同一停止规则、同一冻结查询集、同一契约 A；记录数据／查询／配置哈希。16 与 64 仅块数不同。

**P1 健全性采样（必要，非证明）**：抽样 `(q,B)`，断言

```
LB_sphere ≤ 真最小平方距(B)
LB_stat   ≤ 真最小平方距(B)
LB_B      ≤ 真最小平方距(B)
```

通过率必须 100%。任一违反即实现缺陷（优先查 ρ 是否 RU、中心距离公式、单位映射）。采样零违反**不能**替代全浮点保守算术链（U3）。

**P2 每块每查询字段**：`d_c`、`‖c‖`、`ρ`、`t_m`、`lo_m`、`hi_m`、`width_m`、`LB_sphere`、`LB_stat`、`LB_B`、`真最小平方距(B)`、`d_k^cur`、`K_support_count`、`gap=LB_B−d_k^cur`。

**P3 剪枝归因（D5，统一分母）**：以**全部合法块**为分母，统计 `sphere_only / stat_only / both / neither`；另报"按 oracle 阈值会剪"与"按当前阈值实剪"两套数，不混算。

**P4 阈值合法性（D4 拆分）**：

```
D4a 必要检查：d_k^cur 来自 K 个不同合法支持项；与 LB 同契约同单位；方向保守（LB>d_k^cur 才排除）
D4b 上限诊断：仅离线比较 d_k^cur 与 oracle d_K*，差值记为"相对 oracle 的松弛"，不判错
```

**P5 精化计数（W4）**：`overlap_pairs`、`exact_compares`、`refine_cost`、`wrong_order`（对照精确）、`fake_equal`。前三项是成本，后两项才是错误。

**P6 16 vs 64 描述性对比**：报告 `ρ` 分布、`width_m` 分布、`sphere_only/stat_only/both/neither` 比例随块数的变化；只描述，不由此推性能结论。

**字段需求（缺真实统计，只列不猜）**：每块 `‖c‖`、`ρ`、各子空间 `lo/hi/width` 的分布；`真最小平方距` 分布；`d_k^cur` 与 `K_support_count` 分布；`gap` 分布；精化频次。**不预设 BGE-M3 这些量的取值。**

## 5. 未闭合与边界

- **U1 混合分证书**：RRF（dense50+lex50+rrf60）不接距离证书；需字段：dense 分、lex 分、RRF 参数、每项贡献、K 个支持项。
- **U2 非恒等 OPQ**：搁置，不展开。
- **U3 机器证书**：全浮点输入的保守算术链未闭合；D0 仅采样必要检查。
- **U4 真实分布**：BGE-M3 的 `‖c‖`、`ρ`、残差、剪枝率均未测；不猜、不估收益。
- **契约边界**：A（存储 FP32 实数平方 L2）与 B（f64 内积）、C（RRF 混合）分别处理，不互借阈值。

**一句话**：球界看 `ρ` 与方向填充，统计界看查询是否越出块的子空间偏移范围；两者**不互相支配**，`max` 只是安全组合而非最优性主张。修正后仍成立的只有：两界各自保守、重叠须精化、在线阈值只需合法与保守、单位与契约不得混用。
