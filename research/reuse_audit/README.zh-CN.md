# 状态复用机会与成本上限审计 · 2026-11-07

[English](README.md) | [简体中文](README.zh-CN.md)

本轮完成现有负载核对、小范围证据审阅及成本组成诊断，尚未选择或实现新的架构机制。缺少真实请求局部性和可重放的自然更新历史，语义标签也仍是助手初审。因此，下面的结果只用于判断下一步需要什么证据，不作为架构收益实验。上一轮几何界负结果保持不变。

## 负载与证据数据卡

原冻结修订包含 114 个来源、1,213 个片段、BGE-M3 dense1024 向量。90 条来源元数据具有 updated 字段，但其真实时间含义未独立核实。可用问题是 16 组人工编写的三种问法，共 48 个不同文本；排列顺序不是自然会话。数据库 journal 的 1,216 行只有 `seq`、`id`，缺少时间、操作类型和变更前后正文。四份聚合状态也不足以构成请求时间线或自然更新重放。阶段一另外的 120 族 seed-qrels／抽查资料没有随数据包提供，本轮没有打开封存划分。

我阅读每个锚点按规范向量评分排前二的片段，并把这同一对证据分别对照三种问法，形成 **48 问、96 条助手初审判断**。私有标签绑定问题哈希、片段 ID、版本和正文哈希，明确标为临时、未经用户确认的判断；未审片段仍为未知。本轮没有正式 nDCG@10、池内召回、已核实可回答性或当前权威性结论。

| 固定审阅对内的初审结果 | 数量 |
|---|---:|
| 0／1／2 分证据判断 | 30／37／29 |
| 至少有一条直接支持证据的问题 | 21／48 |
| 两条证据均判无关的问题 | 12／48 |
| 其余仅有相关线索、没有直接支持的问题 | 15／48 |

这些数字不是 top-2 精确率、top-10 质量或全库可回答率；候选对来自锚点，不是每个改写自身的前二。初审暴露了主题接近但不支持所问、导航替代方法、历史材料被当成现役步骤、已处理原件不足以证明当前待办，以及复合问题只覆盖部分要求等情况。主题相关和当前权威也必须分开判断。私有审阅包与逐条理由不进入 Git。

## 控制条件下的成本观察

测量前先固定[协议](protocol.json)。未修改的阶段二 full、ANN50／ef128、hybrid 使用同一隔离常驻快照、来源核验和 SQLite FULL 完成提交；每个后端先有一次单独计费的普通预热。48 个不同问题×3 后端×3 次重复共 **432 条测量**，每问每轮轮换后端执行顺序，这段测量关闭精确请求结果缓存。初始化、导入和预热仍保留在私有记录与汇总中。数字来自当前 Linux／Python 环境，不代表用户 Windows 主机。

| 后端 | 总耗时中位数 ms | 理想删去规范评分的成本占比 | 理想删去物化正文核验的成本占比 | 普通缓存受控未命中／命中 ms |
|---|---:|---:|---:|---:|
| full | 4.361 | 30.55% | 1.20% | 4.379／1.571 |
| ANN | 2.991 | 3.04% | 1.62% | 2.995／1.557 |
| hybrid | 8.475 | 1.14% | 0.61% | 8.677／1.600 |

占比是逐查询“组件／总耗时”比例的中位数，假设整个组件免费消失且没有替代开销。查询改变后的分数、权限和来源核验通常不能如此删除，所以它只是乐观上限，不是实际节省。来源工作在这里是检查和哈希快照中的物化正文，不包含原文件取回、解析、云端 I/O 或生成；不能把很小的来源占比外推为真实系统没有来源 I/O 机会。

hybrid 的词法子阶段在该参考实现中约占 **61.64%**，规范重排约 **1.14%**；full 的全量规范评分较重，但 ANN 已只重排 50 个候选。这提示先核实质量与普通词法／索引工程成本，再讨论共享状态新增价值；本轮没有确认语义同等，也没有据此选择新机制。`prepare` 已包含 ANN 和词法子阶段，不与子阶段重复相加。完成提交始终按同一规则计费。

另外 **144 对“未命中→立即相同请求命中”**核验普通精确请求缓存。所有对照返回 ID 一致；命中仍有十次来源读取／检查、一次完成提交，规范重评分为零。这是人为控制的基线设施，不是自然命中率或 SERA 的新增贡献。48 个问题因构造而各不相同，也不能反过来用作真实未命中率。

## 盈亏平衡与当前决定

预存锚点哈希、排除自身向量后，16 锚点匹配的中位数约 **0.0172 ms**；每次独立匹配有 16 次评分、131,072 B 逻辑查询向量读取。这还没有包含候选载荷查找、填充和失效，只是乐观的额外开销参考，不是完整候选复用成本。

至少需要满足 `p × 可省成本 > 匹配 + 填充／复用次数 + 维护`。真实有效命中概率、摊销次数与更新维护成本未知，均保留为空。只保留匹配开销时，full／ANN／hybrid 的“仅省来源”概率门槛约为 32.7%／35.2%／33.6%，“仅省规范评分”约为 1.3%／19.3%／18.6%。这不是可行性预测：质量不退化的有效复用和被省略的成本尚未测得。即使免费删去全部来源核验，也只对应本截面约 0.6–1.6% 总成本。

本轮据此不新开架构机制实现。下一步需要带范围／快照身份的自然查询序列，以及带操作类型、受影响条目、前后版本或不可变载荷引用的更新记录；缺字段如实留空。语义审阅应扩展到 full／ANN／hybrid 共用判定池，经过独立或用户裁决，并分别处理当前权威性和多侧面覆盖。本轮没有启动被动日志采集、插件修改、模型训练或新嵌入调用。
